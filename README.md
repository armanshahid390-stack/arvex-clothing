# ARVEX Clothing Website

A responsive B2B apparel manufacturing website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `arvex-clothing`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Important customization
- Replace the Unsplash image URLs in `style.css` with your own factory/product photographs.
- Update the email and WhatsApp number in `index.html` if your contact details change.
- The quote form uses the visitor's email application via `mailto:`. For a form that submits directly from the browser without opening an email app, connect a service such as Formspree or another form backend later.
